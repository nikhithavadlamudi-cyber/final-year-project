METHODOLOGY NOTICE Cloud-Aware Memory Extraction & Volatile Evidence Boundary
IaaS vs. SaaS Distinction
Infrastructure as a Service (IaaS)

Analyzes authorized volatile memory snapshots (RAW, MEM, DMP) captured from Guest Virtual Machines (e.g., AWS EC2, Azure VM, GCP Compute Engine). Evidence integrity is strictly preserved via SHA-256 verification.

Software as a Service (SaaS) Boundary

Direct physical host RAM access is strictly isolated by cloud service providers. SaaS forensics relies on API audit logs, tenant exports, and provider-assisted evidence rather than direct hypervisor memory acquisition.
